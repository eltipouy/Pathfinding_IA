# 💻 EJERCICIO | PATHFINDING EN UNITY | ING. EN VIDEOJUEGOS 🎮

¡Bienvenidos al ejercicio de **Pathfinding con el algoritmo A\*** en Unity!

Este proyecto fue desarrollado con fines educativos para estudiantes de **Ingeniería en Videojuegos**, como parte de la materia **Inteligencia Artificial Aplicada en Videojuegos**.

A través de este ejercicio podrás explorar cómo implementar un algoritmo de búsqueda de caminos (*Pathfinding*) utilizando Unity, aprendiendo cómo un agente puede encontrar una ruta para desplazarse desde un punto de origen hasta un destino dentro de un entorno de juego 2D.

## 🎯 Objetivo del proyecto

Comprender los fundamentos del algoritmo A* (*A-Star*) y su aplicación en videojuegos, mediante la implementación de un sistema de búsqueda de caminos que pueda utilizarse como base para el movimiento de personajes y agentes en un juego de plataformas 2D.

## 🛠️ Tecnologías utilizadas

- **Motor de desarrollo:** Unity
- **Lenguaje de programación:** C#
- **Algoritmo de búsqueda:** A* (*A-Star*)
- **Tipo de proyecto:** Ejercicio práctico de inteligencia artificial aplicada a videojuegos
- **Entorno de aplicación:** Videojuegos 2D
